# Analysing German parliamentary debates: a special case of calls to order

This repository supports a submission accepted to the PoliticalNLP 2026 (LREC 2026 Workshop) that explores incivility in parliamentary discourse, focusing on calls to order (CtO; plural: CtOs) in the German parliament.

## Files description

| Document  | Description | Columns |
|----------|----------|----------|
| cto_corpus_speeches.json   | Contains complete speeches of politicians in Bundestag containing a CtO or its cause |'date': date of the speech <br> 'legislativeperiod': legislative period <br> 'sessionno': number of the session <br> 'url': url to the source file <br> 'agenda_type': type of the agenda <br> 'speech_id': ID of a speech <br> 'speech_nr': numbered of the speech <br> 'speaker_full_name': name of the speaker <br> 'role': speaker's role <br> 'party': speaker's party<br> 'speaker_id': ID of the speaker; corresponds to the 'ID' column in pm_info.json <br> 'classification': speech topic 'speech': speech split to sentences. Each sentence has 'sen_nr': number of sentence in speech and 'type': speech, call to order, or interjection|
| relations_cto_cause.json    | Contains relations showing which sentence from cto_corpus_speeches.json caused corresponding CtO and name of a parliamentary member (PM) called to order  |'cto_id': ID of CtO <br>  'cto_speech_id': speech ID containing call to order; corresponds with 'speech_id' in cto_corpus_speeches.json <br> 'cto_sen_nr': number of sentence in speech containing call to order; corresponds with 'sen_nr' in cto_corpus_speeches.json <br> 'clas': classification of the cause triggered CtO <br> 'cause_id': ID of a cause triggered CtO <br> 'cause_speech_id': speech ID containing corresponding cause; corresponds with 'speech_id' in cto_corpus_speeches.json <br> 'cause_sen_nr': number of sentence in speech containing cause; corresponds with 'sen_nr' in cto_corpus_speeches.json <br> 'pm_called_to_order': PM called to order. Each entry comprises: 'name': name of PM called to order, 'speaker_id': ID of PM called to order, which corresponds to the 'ID' column in pm_info.json, 'name_disambiguated': True or False. Shows if PM was disambiguated. |
| pm_info.json    | Contains a subset of a list of all members of parliament; restricted to PMs from cto_corpus_speeches.json. Retrieved from [Bundestag Opendata](https://www.bundestag.de/services/opendata) | see description at [Bundestag Opendata](https://www.bundestag.de/services/opendata) |
| find_cto.ipynb    | Script with the rule-based approach to detect CtOs in a speech.  | |
